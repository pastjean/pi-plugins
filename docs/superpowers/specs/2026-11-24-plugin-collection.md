# Pi plugin collection

Rename the checkout and GitHub repository to `pi-plugins`. The root is a catalog and exposes no Pi skills. Install each plugin from its own local directory. Preserve pstack command names, playbooks and license.

Thermos ports Cursor's two diff-scoped review rubrics and combined review skill. Both passes use the same scope. Run inline on stock Pi or in parallel with authorized delegation. No runtime extension or dependency on pstack.
