# Prompts worth copying

Replace the brackets with real inputs and checks. Start with one prompt, not a chain of skills.

- Understand: `/skill:how Trace [request] from the route to the stored row. Point me to the files; don't edit yet.`
- Resume: `/skill:recall Where did we leave [topic] in this workspace last week? Check the branch before recommending the next move.`
- Debug: `/skill:poteto-mode [Input] produces [wrong output]. Reproduce it, fix it, then show the same input producing [expected output].`
- Refactor: `/skill:poteto-mode Move [logic] into one module. Record output on [fixture] first and compare it byte for byte afterward.`
- Plan: `/skill:poteto-mode Turn [design] into small changes, each with a pass/fail check. Stop at the plan.`
- Review: `/skill:blast-radius What could changing [field] break outside this diff? Trace its readers before drawing a conclusion.`
- Customize: `/skill:automate-me Draft a mode skill from my answers. Ask what I want to verify before calling a task done.`
